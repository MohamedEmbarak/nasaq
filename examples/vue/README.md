# Nasaq Vue example

From the workspace root after building packages:

```sh
pnpm --filter @nasaq/example-vue dev
```

Opens the local example on port 4176. Arabic/English, RTL/LTR, theme, appearance
and density can be changed independently. Complete the application, review it in
a native modal, and submit it to the in-memory request list. Nothing is sent to a
server, and page reload clears changes. All 27 Vue components appear in the form,
request list or components tab.
