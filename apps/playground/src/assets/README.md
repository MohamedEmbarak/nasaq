# Guide attribution artwork

`nic-logo.webp` is the National Information Center (NIC) image supplied by the
project requester for the guide's header attribution. The supplied source image
is retained unchanged. Dark mode displays it in white through a CSS filter;
this is a presentation treatment, not a separate supplied logo variant.

The NIC name, logo, and associated rights remain with their respective rights
holders. Supplying or including this image does not imply an Apache 2.0 license
for the artwork or grant permission to use the NIC trademark. The project's
